ToastFish 使用说明

一个常驻系统托盘的背单词工具：按一下 Alt+Q，单词自己找上门。

三步上手

1按 Alt+Q

弹出第一个单词。再按一次可以暂停 / 恢复。

2按 Alt+1~Alt+4

告诉它记没记住。不想用键盘，直接点弹窗上的按钮也一样。

3剩下的它来

学完自动进入复盘测验和学后阅读，下次复习时间由算法安排。

程序启动后不会弹主窗口，而是缩到任务栏右下角的系统托盘。找不到图标就点任务栏的 ^ 展开，橙色小鱼就是它；按住可以拖到任务栏上固定显示。

弹窗放着不答（约 3 分钟）会按「没印象」处理，不会卡住你。

一轮学习会发生什么

1. 学习

弹窗依次展示单词卡：音标、词性释义、例句、词组，需要的话可以自动朗读。你按 Alt+1~Alt+4 告诉它记没记住。

2. 复盘测验

学完这一轮的词后自动出选择题（中译英 / 英译中），按 Alt+1~Alt+3 选答案。答错会提示正确答案。

3. 学后阅读

刚学的词组成例句串读或 AI 短文，目标词橙色高亮。点击任意英文单词会用浏览器打开有道词典查词。

4. 统计

一轮结束显示本轮数据。历史进度随时看「学习报告」。

进阶玩法

惊喜复习

平时用电脑时，每次按键 / 鼠标点击 / 手柄操作有 0.5% 概率弹出一个迷你测验：一个单词 + 三个选项，Alt+1~3 作答。答对巩固记忆，答错给 3 秒正确答案，60 秒不答算错。学习轮次进行中不会触发，不会打断你。

学后阅读：AI 短文（可选）

默认是离线的「例句串读」。想要 AI 生成的短文：托盘 参数设置 → 学后AI短文，首次开启会引导填 API Key。支持 DeepSeek（默认）、Kimi 开放平台、Kimi Code 订阅、以及任意 OpenAI 兼容端点。不填 Key 也能用，只是会回退成例句串读。

短文里划重点

AI 短文与完形填空弹窗底部有 ✎ 划重点 按钮：点一下进入划线模式，用鼠标拖动选中任意一段文字就画上下划线。同一处可以反复划，线条一层层错开、颜色按五色循环，适合「先划主干、再划修饰」；想擦掉某一层，在划线处点右键即可，或按「清除划线」一次清空。划线跟在文字上，滚动、Alt 放大都同步；只保存在当前弹窗里，关掉窗口就没了。

考研精读：长难句拆解 + 英译汉

选考研词库时，AI 短文测验结束后的结算面板会多出一个「开始精读」：先逐句拆解长难句 —— 主干是哪个成分、每个从句与修饰起什么作用、整句怎么翻译；再挑出两句让你自己写译文，提交后由 AI 按「意思准确 6 + 通顺 2 + 结构 2」打分，并列出命中要点、漏译或欠准之处、总评和参考译法。

精读与短文、题目出自同一次 AI 生成调用，不额外花请求；评分也复用这段对话的上下文，所以点评能对上短文里的具体表达。

学习报告（仪表盘）

托盘 学习报告 📊 会打开本地网页仪表盘：学习曲线、评分分布、正确率趋势、学习日历、词库进度、记忆结构、顽固词排行等。安装包已内置 Python 运行时，开箱即用。

一键更新

启动后自动静默检查新版本（已是最新版时不打扰）。有新版本会问「是否立即更新」—— 点一下就直接下载、静默安装、自动重启，不跳浏览器。网络访问不了 GitHub 时会自动切换备用下载通道；两条都不通会明确告诉你失败原因，也可以手动去 Releases 下载覆盖安装。

自定义词库

托盘 导入单词 支持 Excel 模板（模板位置：安装目录下的 Resources\自定义模板.xlsx）。也可以把导出的学习记录再导进来，重新背一遍。

数据在哪里

所有学习数据都在一个文件里：

%LOCALAPPDATA%\ToastFish\Resources\inami.db

卸载不会删除它，重装后进度自动恢复；换电脑时把这个文件复制到新电脑同一位置即可。

安装目录下的其他运行时文件：Log\ 每日学习记录与 popup.log 弹窗日志、Mp3Cache\ 发音缓存（可随时删）、DbSnapshots\ 数据库自动备份。

常见问题

托盘图标不见了？

点任务栏的 ^ 展开隐藏图标找橙色小鱼，可以拖到任务栏固定。如果进程也没了，重新启动程序即可。

图标右键点不出来 / 快捷键全都没反应？

「什么反应都没有、只能重启」是 v3.4.3 之前的已知问题（部分声卡驱动下界面线程被卡住），升级到最新版即可。如果只是 Alt+Q 不灵，多半是热键被截图工具、输入法、录屏软件占用，关掉再试。

弹窗不出现？

ToastFish 用自绘窗口，不是系统通知 —— 别去「通知中心」找。检查任务管理器里是否有 ToastFish.exe；也可能是被 Alt+H 藏起来了，再按一次。

一轮学习中途卡住 / 按键没反应？

v3.4.1 起已修复「提示消息顶掉答题弹窗」。若仍遇到，按 Alt+Q 会自动中断旧一轮并重新开始，不需要重启程序。

学习报告打不开，鼠标一直转圈？

v3.2.5 起安装包已内置 Python 运行时。若仍失败程序会弹出明确提示，请把提示内容反馈到 GitHub Issues。

安装时提示「未知发布者」/「Windows 已保护你的电脑」？

本程序没有购买代码签名证书，Windows SmartScreen 会对所有未签名程序统一报警。点「更多信息 → 仍要运行」即可。

发音没声音 / 用英语发音会闪退？

到 Windows 设置 → 时间和语言 → 语言 → 添加语言，装上英语语音包后重启程序。也可以在「参数设置」里关掉自动播放，改用 Alt+~ 手动听。

换电脑怎么迁移进度？

把 inami.db 复制到新电脑的 %LOCALAPPDATA%\ToastFish\Resources\ 下；或者在新装时于安装向导里勾选「从旧版本导入学习进度」。

还有别的问题 / 想提建议？

去 GitHub Issues 提，附上版本号、系统版本和截图会快很多。

卸载

设置 → 应用 → 已安装的应用 → ToastFish → 卸载；或运行安装目录下的 unins000.exe。卸载不会删除 inami.db；想彻底清干净，卸载后手动删除 %LOCALAPPDATA%\ToastFish 整个目录。
