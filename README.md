# ToastFish

> **当前版本：v3.2.5** —— 历史版本与更新说明见 [Releases](https://github.com/Zenkuetu/ToastFish/releases)。

> 一款让你**随时随地、被动地**学习英语 / 日语的 Windows 背单词工具。
>
> 常驻系统托盘，主动弹出单词，你只需随手按一下热键作答，在碎片时间里无痛积累词汇量。

## 安装（Windows 10 / 11）

1. 到 [Releases](https://github.com/Zenkuetu/ToastFish/releases/latest) 下载最新的安装包（`ToastFish-v3.2.5-Setup.exe`）。
2. 双击运行。**无需管理员权限**，默认安装到 `%LOCALAPPDATA%\ToastFish`。
3. 从开始菜单（或桌面快捷方式）启动，程序会最小化到系统托盘。

> ### ⚠️ 首次运行时可能提示「未知发布者」或「Windows 已保护你的电脑」
>
> 这是**正常现象**：本项目**没有做数字签名**（代码签名证书需要付费购买），因此 Windows Defender SmartScreen 会对所有未签名程序给出这个提示。
>
> **解决办法：点击「更多信息」→「仍要运行」即可。**
>
> 如果你信任本项目，也可以在「Windows 安全中心 → 应用和浏览器控制 → 基于信誉的保护」中关闭「检查应用和文件」，这样所有未签名程序都不再提示（该设置会降低系统整体防护，请自行权衡）。

> 卸载不会删除学习数据，重装自动恢复（见下方「数据存储」）。

## 快速上手（3 步）

1. **启动**：双击 `ToastFish.exe`（或安装包安装后启动），程序最小化到系统托盘（任务栏右下角）。
2. **开始**：按 `Alt+Q` 开始一轮学习。
3. **作答**：弹窗出现单词后，按 `Alt+1` ~ `Alt+4` 选择记忆程度。

学完一轮会自动进入复盘测验和学后阅读。就这么简单。

## 热键速查

| 热键 | 作用 |
|------|------|
| `Alt+Q` | 开始 / 停止学习 |
| `Alt+1` | 没印象（Again） |
| `Alt+2` | 模糊（Hard） |
| `Alt+3` | 记住（Good） |
| `Alt+4` | 牢记（Easy） |
| `Alt+~` | 重复播放发音 |
| `Alt+H` | 显示 / 隐藏当前弹窗 |

> 也可用鼠标直接点击弹窗上的按钮。弹窗超时未答会被视为「没印象」。

## 托盘菜单功能

右键点击托盘图标可访问全部功能：

| 菜单 | 说明 |
|------|------|
| 开始 / 停止 | 开始或停止一轮学习（`Alt+Q`） |
| 选择词库 | 切换词表（CET4/6、考研、雅思、托福、GRE 等 16 套 + 日语 + 五十音） |
| 设置单词数量 | 每轮新词数（默认 5） |
| 发音选择 | 英式 / 美式 |
| 自动播放 | 弹窗时自动朗读 |
| 开机自启 | 随 Windows 启动 |
| 导入单词 | 用 Excel 模板导入自定义词表 |
| 测试 | 随机抽词测验 |
| 学习报告 | 打开可视化学习仪表盘 |
| 参数设置 | AI 短文 / 测试模式等 |
| 使用说明 | 原版图文教程 |
| 退出 | 关闭程序并保存学习记录 |

## 学习流程详解

1. 按 `Alt+Q` 开始，弹窗依次展示单词（音标、词性释义、例句、词组）。
2. 按 `Alt+1~4` 作答，程序依据记忆程度自动安排下次复习时间。
3. 一轮结束 → **复盘测验**（中译英 / 英译中选择题）→ **学后阅读** → 统计面板。

**学后阅读**：刚学的单词会组成例句串读或 AI 短文，目标词橙色高亮；阅读时点击任意英文单词即可查有道词典（悬停变手型）。

**惊喜复习**：平时用电脑时，键盘 / 鼠标 / 手柄操作有 0.5% 概率弹出一个迷你测验，答对巩固记忆，不会打断当前学习。

## 常见问题

**快捷键没反应？** 可能被其他软件占用全局热键（截图软件、输入法等），关闭后重试。

**弹窗不出现？** 检查任务管理器确认进程存在；本工具用自绘窗口，不是系统通知，勿在通知中心查找。

**如何迁移到新电脑？** 复制上面的 `inami.db` 到新电脑同位置即可。

**安装/启动时提示「未知发布者」或「Windows 已保护你的电脑」？** 因为程序未做数字签名 —— 点「更多信息 → 仍要运行」即可，详见上方[「安装」](#安装windows-10--11)一节。

**托盘图标不见了？** 点任务栏的 `^`（显示隐藏的图标）找找；找到后可直接拖到任务栏固定显示。

**仪表盘打不开（只有转圈）？** v3.2.5 起安装包已内置 Python 运行时，若仍失败会弹出明确的错误提示，请把提示内容反馈到 [Issues](https://github.com/Zenkuetu/ToastFish/issues)。
