# ToastFish

**常驻托盘的背单词工具：按一下 `Alt+Q`，单词自己找上门。**

支持英语（四级 / 六级 / 考研 / 雅思 / 托福 / GRE / GMAT / 专四专八）与日语（五十音 / 标准日本语中级），Windows 10 / 11 可用，免费、开源、无广告。

## 这是什么

一个**不需要你坐下来「进入学习状态」**的背单词工具：

- **按一下就开始** —— `Alt+Q` 弹出第一个单词，`Alt+1`~`Alt+4` 选记忆程度，一个词 2 秒。
- **不打扰你干别的事** —— 只占屏幕右下角一小块，随时 `Alt+H` 收起。
- **它自己找你** —— 平时用电脑时，键盘 / 鼠标操作有 0.5% 概率弹出一个迷你测验。
- **不用做计划** —— 复习时间由 SM2+ 间隔重复算法安排，到点自动出现。

> 它不是又一个「打开 App、找到词表、点开始」的学习软件 —— 那些步骤正是你放弃的原因。

## 30 秒上手

**1. 下载安装包**

到 [Releases](https://github.com/Zenkuetu/ToastFish/releases/latest) 下载 `ToastFish-v3.4.3-Setup.exe`（约 34 MB）。

**2. 双击安装**

- **无需管理员权限**，默认装到 `%LOCALAPPDATA%\ToastFish`（当前用户目录）。
- 如果在 Windows 10 / 11 上看到蓝色窗口「Windows 已保护你的电脑」或「未知发布者」：点 **更多信息 → 仍要运行**。这是正常的，因为本项目没有购买代码签名证书（详见[常见问题](#常见问题)）。
- 安装向导里选「标准安装（推荐）」即可；升级用户可以勾选「导入旧版学习数据」保留进度。

**3. 启动**

装完直接启动（或从开始菜单 / 桌面快捷方式启动）。程序**不会弹出主窗口**，而是缩到任务栏右下角的系统托盘。

> 找不到图标？点任务栏的 `^`（显示隐藏的图标）→ 里面有一个橙色小鱼。可以按住拖到任务栏上固定显示。

**4. 按 `Alt+Q` 开始学习，按 `Alt+1`~`Alt+4` 作答。**

就这三步。剩下的交给它。

## 热键速查

| 热键 | 作用 |
|------|------|
| `Alt+Q` | 开始一轮学习 / 中途再按可暂停恢复 |
| `Alt+1` | 没印象（Again）—— 很快会再见到它 |
| `Alt+2` | 模糊（Hard） |
| `Alt+3` | 记住（Good） |
| `Alt+4` | 牢记（Easy）—— 隔得更久才复习 |
| `Alt+~` | 重播当前单词发音 |
| `Alt+H` | 显示 / 隐藏当前弹窗 |
| 按住 `Alt` | 把当前弹窗**等比放大一倍**（松开还原），适合离屏幕远或看不清时 |

- 不想用快捷键？**直接用鼠标点弹窗上的按钮**也行。
- 弹窗放着不答（约 3 分钟）会按「没印象」处理，不会卡住你。
- 右上角有个 **`A+` 小图标**，点一下可以关掉「按住 Alt 放大」这个功能（默认开启）。

**右键点击**托盘图标打开菜单（左键双击也能开始一轮学习）：

| 菜单 | 说明 |
|------|------|
| 开始! | 开始 / 恢复一轮学习（等同于 `Alt+Q`） |
| 导入单词 | 用 Excel 模板导入自己的词表 |
| 英语词汇 ▸ | 切换英语词库（四级 / 六级 / 考研 / 雅思 / 托福 / GRE / GMAT / 专四专八） |
| 日语词汇 ▸ | 切换日语词库（标准日本语中级 / 顺序五十音） |
| 随机测试 ▸ | 从**学过的**单词里随机抽题自测（英语 / 日语 / 五十音） |
| 参数设置 ▸ | 每轮单词数、发音口音、自动播放、AI 短文、测试模式、重置进度 |
| 使用说明 ▸ | 快捷键、图文教程、官网、Star 支持、检查更新 |
| 学习报告 📊 | 打开可视化学习仪表盘（在浏览器里） |
| 开机启动 | 勾选后随 Windows 启动 |
| 退出 | 关闭程序（会先保存学习记录） |

## 一轮学习会发生什么

1. **学习**：弹窗依次展示单词卡（发音、词性释义、例句、词组）。你按 `Alt+1`~`4` 告诉它记没记住。
2. **测验**：学完自动进入复盘测验，从刚学的词里出选择题（中译英 / 英译中），`Alt+1`~`3` 选答案。
3. **学后阅读**：刚学的词组织成例句串读或 AI 短文，目标词橙色高亮。阅读时**点任意英文单词**会打开有道词典。
4. **统计**：一轮结束显示本轮数据；历史数据可随时在「学习报告」里看。

> 全程都在右下角的小窗口里完成，不会弹全屏、不会抢焦点、不会打断你正在做的事。

## 进阶玩法

### 惊喜复习

平时用电脑时，每次按键 / 鼠标点击 / 手柄操作有 **0.5%** 概率弹出一个迷你测验：显示单词 → 三个选项 → `Alt+1`~`3` 作答。答对巩固记忆，答错给 3 秒正确答案，60 秒不答算错。**学习轮次进行中不会触发**，不会打断你。

### 学后阅读：AI 短文（可选）

默认是离线的「例句串读」。想要 AI 生成的短文：托盘 **参数设置 → 学后AI短文**，首次开启会引导填 API Key。支持 **DeepSeek**（默认）、**Kimi 开放平台**、**Kimi Code 订阅**、任意 **OpenAI 兼容**端点。不填 Key 也能用，只是回退成例句串读。

### 学习报告（仪表盘）

托盘 **学习报告 📊** 会打开一个本地网页仪表盘：学习曲线、评分分布、正确率趋势、学习日历、词库进度、记忆结构、顽固词排行等。安装包已内置 Python 运行时，开箱即用。

### 一键更新

启动后自动静默检查 GitHub 是否有新版本（已是最新时不打扰）。有新版本会问「是否立即更新」—— 点「立即更新」就**直接下载、静默安装、自动重启**，不需要跳浏览器。网络连不上 GitHub 时会自动切换备用下载通道；两条都不通会明确告诉你失败原因。

### 自定义词库

托盘 **导入单词** 支持用 Excel 模板导入自己的词表（模板位置：安装目录下的 `Resources\自定义模板.xlsx`）。也支持把导出的学习记录再导入，重新背一遍。

## 文件与数据

所有学习数据都在这**一个文件**里：

```
%LOCALAPPDATA%\ToastFish\Resources\inami.db
```

- **卸载不会删除它**，重装后进度自动恢复。
- **换电脑**：把这个 `inami.db` 复制到新电脑的同一位置即可。
- 迁移到新装环境也可以用安装向导里的「导入旧版学习数据」。

其他运行时文件（都在安装目录下）：

| 路径 | 内容 |
|------|------|
| `Log\` | 每日学习记录（Excel）与弹窗日志 `popup.log` |
| `Mp3Cache\` | 英语发音缓存（可随时删除） |
| `DbSnapshots\` | 数据库自动备份 |

## 常见问题

**安装时提示「未知发布者」/「Windows 已保护你的电脑」？**
本项目没有购买代码签名证书（一年几千元），所以 Windows SmartScreen 会对未签名程序统一报警。这是**正常现象**，点「更多信息 → 仍要运行」。你可以在 GitHub 上核对安装包的 SHA-256（Release 页面附件列表里能看到），确认下载完整。

**托盘图标不见了？**
点任务栏的 `^`（显示隐藏的图标）→ 找到橙色小鱼。想固定显示就把它拖到任务栏上。如果进程确实不在，重新启动程序即可。

**图标右键点不出来 / 按快捷键没反应？**
如果是「什么反应都没有、只能重启」：请先升级到 **v3.4.3 或更高**（旧版在部分声卡驱动下会卡住界面线程，表现就是托盘点不动）。如果只是 `Alt+Q` 不灵，多半是热键被截图工具、输入法、录屏软件等占用，关掉它们再试。

**弹窗不出现？**
ToastFish 用的是**自绘窗口**，不是系统通知 —— 别去「通知中心」找。检查任务管理器里有没有 `ToastFish.exe`；如果弹窗被 `Alt+H` 藏起来了，再按一次 `Alt+H`。

**一轮学习中突然中断 / 按键没反应？**
v3.4.1 起已修复「提示消息顶掉答题弹窗导致卡死」。如果还遇到，按 `Alt+Q` 会自动中断旧一轮并重新开始，不需要重启程序。

**学习报告打不开（鼠标一直转圈）？**
v3.2.5 起安装包内置 Python 运行时。若仍失败，程序会弹出明确提示，请把提示内容发到 [Issues](https://github.com/Zenkuetu/ToastFish/issues)。

**自动更新下载失败？**
多半是网络访问不了 GitHub。程序会先试直连、再试资产 API 通道，都失败时会告诉你是超时还是连接被拒。也可以直接去 Releases 页面手动下载安装包覆盖安装（学习数据不会丢）。

**杀毒软件报毒 / 安装后图标闪一下就没了？**
未签名程序常被误报。如果信任本项目，把安装目录加入白名单后重试。

## 卸载

三种方式任选：

1. Windows 设置 → 应用 → 已安装的应用 → ToastFish → 卸载
2. 开始菜单 → ToastFish → 右键 → 卸载
3. 运行 `%LOCALAPPDATA%\ToastFish\unins000.exe`

> 卸载**不会**删除 `inami.db`。想彻底清干净，卸载后手动删除 `%LOCALAPPDATA%\ToastFish` 整个目录。

## 为什么做这个

我自主性很差 ——「每天背 30 分钟」这类计划，我从没坚持超过一周。卡住我的从来不是内容，而是**「开始」这个动作本身的成本**：打开 App、切到学习界面、坐下来，每一步都在消耗我本来就不多的意志力。

所以这个工具的设计原则只有一条：**不依赖自律，把要做的事直接摆到眼前。**

- **快捷键触发** —— 把「打开 App 学习」压缩成按一个键，摩擦小到不需要下决心。
- **惊喜弹窗** —— 「主动开始」需要意志力，「被动接受」不需要。不是我去找它，是它来找我。
- **不打断正常使用** —— 随时可隐藏，打扰是可控、可撤销的；一个关不掉的提醒只会让人想卸载它。

单词几乎是在眼前「闪现」的，复习时机交给 SM2+ 算法 —— **你不需要做计划，只需要在它跳出来的时候按一下。**
